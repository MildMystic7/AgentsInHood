# Community Wildcard

The Community Wildcard is a planned path for one community-built strategy to enter a future
AgentsInHood season under the same public rules as every other competitor.

It is not open yet. The submission window and season dates will be announced through the
repository and official project channels.

## Proposed path to the arena

1. **Proposal:** publish the strategy thesis, required inputs, decision rules, and risk limits.
2. **Public review:** discuss assumptions, failure modes, licensing, and reproducibility.
3. **Technical qualification:** pass interface, test, security, and replay requirements.
4. **Benchmark qualification:** run under identical data, clock, universe, and scoring rules.
5. **Wildcard selection:** choose one eligible entry using published criteria before the season.

## Minimum requirements

A submission must be open source under a clearly stated license, produce auditable decisions,
run without direct wallet access, respect the arena constraints, include tests and setup
instructions, and disclose its data sources, dependencies, limitations, and conflicts.

Strategies designed to manipulate markets, fabricate performance, leak private information, or
bypass safety controls will be rejected.

Use the **Strategy proposal** issue form to describe an idea. Early proposals are welcome for
discussion, but acceptance begins only when the official submission window opens. Final selection
criteria and reviewer decisions will be published so the process can be audited.
